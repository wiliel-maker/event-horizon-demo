# Горизонт событий

Многостраничный сайт школьной сюжетной 2D-игры с настоящей браузерной сборкой Unity. В демоверсии доступна только первая глава. На компьютере используются клавиатура и мышь, на телефоне появляются экранные стрелки и кнопки. Нужен браузер с WebGL 2.

## Запуск

Публичная демоверсия: https://wiliel-maker.github.io/event-horizon-demo/

Откройте страницу «Играть». «Начать историю» запускает первую главу, «Осмотреть станцию» пропускает вступление. После загрузки нажмите на игровое окно, чтобы передать ему управление.

- A / D или стрелки — движение.
- W / S — подъём и спуск.
- Shift — бег.
- E — взаимодействие; при ремонте удерживать.
- 1–5 — выбор предмета; G — бросить.
- Esc — пауза.

Прогресс в браузерной демоверсии не сохраняется. В полноценной Windows-версии есть отдельная система сохранений.

На телефоне стрелки работают как WASD с удержанием и одновременными касаниями. Рядом доступны действие, бег и предметы. Диалоги и варианты ответа показываются крупными кнопками. При завершении первой главы появляется финальный экран демоверсии.

## Скачивание для Windows

На главной странице есть ссылка на ZIP в GitHub Releases. Это текущая Windows-сборка от 4 ноября 2026 года (52 МБ). Распакуйте архив целиком и запустите Event Horizon.exe. Полная история и новые главы пока разрабатываются.

## Содержимое репозитория

- `index.html` — главная страница игры.
- `world.html` — станция и экипаж.
- `play.html`, `app.js` — запуск Unity.
- `mobile-controls.js`, `mobile.css` — сенсорное управление и мобильные диалоги.
- `tokens.css`, `base.css`, `style.css`, `site.js` — общая система оформления и навигация.
- `game/` — собранная Unity Web-версия. Исходный проект Unity в репозиторий не включён.
- `assets/` — оригинальные изображения игры и шрифты с лицензиями.
- `.nojekyll` — публикация статических файлов через GitHub Pages.

Сборка использует gzip и встроенную в загрузчик распаковку, чтобы работать на статическом хостинге без специальных заголовков Content-Encoding. Для локальной проверки нужен HTTP-сервер; открытие index.html через file:// не подходит для загрузки Unity.

Игра находится в разработке. Мобильная демоверсия обновлена 10 ноября 2026 года.
