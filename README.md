# Event Horizon — браузерная демоверсия

Демонстрационная версия реального Unity-прототипа для школьного проекта «Игры и их проектирование». В игре доступна первая глава. Страница рассчитана на компьютер с клавиатурой, мышью и браузером с WebGL 2.

## Запуск

Публичная демоверсия: https://wiliel-maker.github.io/event-horizon-demo/

Откройте опубликованный сайт GitHub Pages и нажмите «Загрузить игру». «Быстрый осмотр» запускает прогулку по станции, пропуская вступление. После загрузки нажмите на игровое окно, чтобы передать ему управление.

- A / D или стрелки — движение.
- W / S — подъём и спуск.
- Shift — бег.
- E — взаимодействие; при ремонте удерживать.
- 1–5 — выбор предмета; G — бросить.
- Esc — пауза.

Прогресс в браузерной демоверсии не сохраняется. В полноценной Windows-версии есть отдельная система сохранений.

## Содержимое репозитория

- `index.html`, `style.css`, `app.js` — страница запуска.
- `game/` — собранная Unity Web-версия. Исходный проект Unity в репозиторий не включён.
- `assets/walking.gif` — запись настоящего движения для показа без запуска игры.
- `assets/walking.mp4` — та же запись в формате видео для автономного показа.
- `.nojekyll` — публикация статических файлов через GitHub Pages.

Сборка использует gzip и встроенную в загрузчик распаковку, чтобы работать на статическом хостинге без специальных заголовков Content-Encoding. Для локальной проверки нужен HTTP-сервер; открытие index.html через file:// не подходит для загрузки Unity.
